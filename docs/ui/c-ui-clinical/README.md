# C-UI clinical and operations display evidence

Forty-six screenshots show twenty changed component views and their nested states at 390 and1440 CSS pixels. The production SPA runs with synthetic API responses; external traffic is blocked. Sixteen browser cases check the adopted design class, minimum44px control height,8px corners and in-viewport bounds, plus no sideways page overflow. Run `npm run e2e:clinical-form-display` from `hospital-portal`. The configuration builds the production application before running. `manifest.json` records the source commit and SHA-256 of each screenshot. These captures are local browser evidence, not physical-device, deployed-dev or scorecard acceptance.
